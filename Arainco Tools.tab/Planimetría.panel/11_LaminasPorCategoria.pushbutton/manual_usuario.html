Arainco: Láminas por categoría

Crea láminas vacías (sin vistas) con el nombre CONTENIDO LAMINA, numeración PG-001, cajetín elegido y datos de firma/fecha. Equivale al script Dynamo Láminas por categoría.

Requisitos

  • Plantilla / proyecto Arainco preparado para emisión.
  • Al menos un tipo de cajetín (Title Block), distinto de EST_A_SPLASH SCREEN.
  • Parámetro de proyecto Clasificacion en láminas.

Uso

  1. Elija el tipo de formato (cajetín).
  2. Elija la categoría (el código corto, p. ej. PG, se escribe en Clasificacion y en el número).
  3. Indique cuántas láminas crear.
  4. Complete Calculó, Revisó, Aprobó, Dibujó y la fecha.
  5. Pulse Crear láminas.

Numeración

Se buscan láminas con Clasificacion igual a la categoría elegida, se toma el mayor sufijo numérico tras el guion y se continúa (PG-012 → siguiente PG-013). Pad a 3 dígitos. El nombre es siempre CONTENIDO LAMINA.

Si una lámina de esa categoría tiene un número que no es CAT-NNN (sin guion, o sufijo no numérico como PG-A01), se omite para el correlativo y se avisa. No se reutiliza un Sheet Number ya ocupado en el proyecto.

Personas

Las listas se editan en BIMTools.extension/scripts/laminas_por_categoria/personas.json. Cada rol (calculo, revision, aprobacion, dibujo) tiene items y default_index (índice sobre la lista ya ordenada alfabéticamente, como en Dynamo).

ParámetroOrigen
