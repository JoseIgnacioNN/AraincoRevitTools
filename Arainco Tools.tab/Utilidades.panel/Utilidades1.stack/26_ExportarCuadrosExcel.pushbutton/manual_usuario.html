Arainco: Exportar cuadros Excel

Exporta las tablas del proyecto (cuadros de cantidades, cuadros de claves y mediciones de materiales) a un libro Excel. Puede filtrar la lista, marcar las tablas que necesita y generar un archivo con una hoja por cada tabla seleccionada.

Requisitos

  • Revit 2024, 2025 o 2026 con un modelo abierto.
  • Microsoft Excel instalado en el equipo (la exportación usa Excel).
  • Tablas existentes en el proyecto (no se exportan plantillas de tabla).
  • Permiso de escritura en la carpeta de destino del archivo .xlsx.

Uso

  1. Abra la herramienta. Aparece la lista de tablas del proyecto.
  2. Filtre por nombre, categoría o tipo si la lista es larga.
  3. Marque las tablas a exportar. El recuadro del encabezado marca o anula todas las filas visibles.
  4. Con Mayús + clic en la casilla puede seleccionar un rango.
  5. Elija si aplica formato Arainco o solo datos.
  6. Pulse Examinar… y elija la ruta del archivo Excel.
  7. Pulse Exportar. Al terminar puede abrir el libro generado.

Actualizar vuelve a leer las tablas del modelo. Si la herramienta ya está abierta, no se crea una segunda ventana.

Reglas de negocio

Tema Comportamiento
Qué se exporta Tablas del proyecto (ViewSchedule). Se excluyen plantillas de tabla.
Libro Excel Un archivo .xlsx con una hoja por cada tabla marcada. El nombre de hoja se recorta a 31 caracteres y se evitan duplicados.
Contenido Se copia el texto visible de la tabla (cabeceras, filas de datos, agrupaciones y totales cuando existen).
Anchos de columna Se toman de la tabla en Revit y se aplican en Excel.
Formato Arainco Añade cabecera (proyecto, modelo, fecha), encabezados azules, filas alternas, resalte de totales y filtro automático. Si se desmarca, se exportan solo los datos.
Nombre sugerido AAAA.MM.DD_<modelo>_cuadros.xlsx

Notas

  • Hace falta Excel; si no está instalado o queda bloqueado, la exportación falla.
  • Debe marcar al menos una tabla e indicar una carpeta de destino válida.
  • Durante la exportación se bloquea la ventana de Revit hasta terminar.
  • La herramienta no crea ni modifica tablas en el modelo; solo lee y escribe el Excel.
  • Si Excel tiene el archivo abierto, no se podrá sobrescribir.
