Arainco: Dividir y Traslapar

Divide una Structural Rebar en varios tramos con traslape según el diámetro y el grado de hormigón. Tras aplicar, cada tramo modelado queda etiquetado y con anotación multi-barra de recorrido.

Requisitos

  • Revit 2024–2026 y proyecto / plantilla Arainco.
  • Vista de planta, alzado o sección (no plantilla ni 3D) para etiquetas y MRA.
  • Familia de etiqueta EST_A_STRUCTURAL REBAR TAG (o variante FLOOR) cargada.
  • Tipo de Multi-Rebar Annotation Recorrido Barras en el proyecto.
  • Barra elegible: layout Single, Fixed Number o Maximum Spacing con tramos rectos.

Uso

  1. Ejecute la herramienta y seleccione una Structural Rebar.
  2. En el esquema de alzado, haga clic sobre la barra para añadir cortes; clic cerca de un C# para quitarlo. Use la rueda del ratón para acercar o alejar (el zoom se centra en el cursor) y el botón medio arrastrando para desplazar el dibujo. Los botones − / + / 100% encima del esquema hacen lo mismo.
  3. Afine los largos fabricados (mm) de cada tramo, el grado de hormigón y el modo de traslape.
  4. Pulse Aplicar.

Reglas de negocio

  • Los puntos de corte se definen solo en el canvas del esquema (ya no se marcan en la vista de Revit). El zoom y el desplazamiento del esquema no alteran los cortes; solo cambian la vista del dibujo.
  • Se generan N+1 tramos con solape según tabla (Base / G25 / G35 / G45).
  • Se heredan parámetros Armadura_*, presentación (Show Middle / FirstLast / …) y Unobscured en la vista activa.
  • Etiquetas: si la barra original tenía IndependentTag, se recrean en esas vistas con tipo según RebarShape. Si no, se crea etiqueta EST_A en la vista activa.
  • MRA: se crea una Multi-Rebar Annotation «Recorrido Barras» por cada tramo nuevo en la vista activa, para indicar el recorrido del conjunto.
  • Se pueden colocar detalles de empalme (y cotas) según la vista.

Notas / avisos

  • En vista 3D no se crean etiquetas ni MRA; use planta, alzado o sección.
  • Si falta la familia de etiqueta o el tipo «Recorrido Barras», la división sí se aplica y el resumen avisará lo omitido.
  • Free-form / NumberWithSpacing no son elegibles.
